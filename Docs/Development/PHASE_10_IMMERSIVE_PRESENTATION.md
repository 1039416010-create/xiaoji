# Phase 10：3D 角色表现、下注热身、全屏与动态结算

## 目标

解决试玩中发现的四个表现问题：整鸡贴图缺乏肢体动作、13 名角色视觉重复、下注时看不到参赛鸡、结算仅为文字。同时增加 Windows 全屏/窗口可见按钮。

## 实现范围

1. 新增单摄像机 RenderTexture 3D 舞台，供热身、下注、比赛和结算四个 UI 界面复用。
2. 使用 Unity 基础 Mesh 程序化组成身体、头、眼睛、翅膀、双腿、脚和饰品；禁止碰撞和 Root Motion 影响赛果。
3. 13 个稳定鸡 ID 分别拥有独立配色、体型、步态、气质与唯一饰品。
4. `ChickenController` 继续独占进度；3D 舞台只读取 `NormalizedProgress`、`VisualState` 和事件阶段。
5. 跌倒事件前半播放跌倒、后半播放爬起；转身期间模型转向并继续迈腿。
6. Warmup 和 Betting 状态显示同一当前阵容、五条预览赛道及循环热身动作；锁定下注前不生成赛果。
7. 设置页新增 `UI_Button_Fullscreen`，通过 `Screen.SetResolution` 在 `FullScreenWindow` 与 `Windowed` 间切换并保存。
8. 结算页使用 GPT 生成领奖台背景和四份咖喱鸡排饭图集，实时显示冠军 3D 模型、跳跃振翅、飘落彩纸和玩家结算。

## 验收标准

- 13 个角色的视觉配置、饰品和体型均唯一。
- 五只上场鸡在热身、下注、倒计时和比赛中保持同一阵容与赛道顺序。
- 跑步时双腿交替；Trip 可看到倒地和爬起；TurnAround 可看到 180° 转身与反向步态。
- 3D 模型不参与碰撞、不改变进度、不决定冠军。
- 全屏切换只通过可见 Button，重启后保留设置。
- 结算页显示冠军名字、领奖台冠军、四份餐点和彩纸动画。
- EditMode、PlayMode、Windows Development Build 通过并生成 1920×960 截图。
