# ADR-0002：跳过当前版本的实体硬件验收

日期：2026-09-15

状态：已接受（项目方明确决定）

## 背景

Phase 08 原计划在目标 Windows 主机、180×90 cm 投影桌面和 Windows HID 红外多点触控框上完成映射、4/10 点并发、边缘触控、断连恢复和 60 分钟稳定性验收。当前开发环境未连接这些设备，系统探测到 Present HIDClass 设备数为 0。

## 决定

项目方明确指示当前步骤可以跳过。本版本不再等待实体硬件验收，软件阶段按“硬件验收豁免”收口。

该决定只豁免执行，不把未执行项目记为通过，也不改变游戏仍以 Windows HID 红外多点触控和 180×90 cm 桌面投影为目标的产品契约。

## 未采用方案

- 等待目标硬件到位后再关闭 Phase 08：项目方选择跳过。
- 用鼠标、自动化按钮或开发机显示器代替实体触控证据：会产生虚假验收，因此拒绝。
- 把未测试项目直接标记为通过：不符合项目质量规范，因此拒绝。

## 后果

- 软件自动化、Development/Release 构建、冷启动、10,000 种子与 500 局逻辑 soak 结果仍然有效。
- 投影几何、触控坐标、4/10 点并发、边缘误触、设备重连、现场帧时间和 60 分钟稳定性风险由项目方接受。
- 发布包继续使用 `0.1.0-rc1` 标识；可以用于演示或后续现场验证，但不获得“实体硬件已验收”的声明。
- 若未来接入目标设备，应重新启用 `HARDWARE_ACCEPTANCE.md`，无需修改游戏规则或重新设计校准工具。
