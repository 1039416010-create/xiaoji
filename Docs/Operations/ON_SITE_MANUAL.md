# 《走地鸡王》现场部署与操作手册

## 1. 推荐部署参数

- 操作系统：Windows 10/11 x64，关闭系统通知、自动休眠和展示时段内的自动更新重启。
- Windows 显示缩放：优先 100%，并在验收表中记录实际值。
- 投影有效区域：180 × 90 cm，画面比例 2:1，推荐输出 1920 × 960；若设备输出 1920 × 1080，应保留上下黑边，禁止非等比拉伸。
- 游戏目录：复制整个 `GroundChickenKing-Release` 文件夹，不可只复制 exe。
- 输入：红外框应作为 Windows HID 多点触控设备识别；游戏不需要键盘或网络。

## 2. 每日开机

1. 开启投影机和红外触控框，等待 Windows 完成设备识别。
2. 确认投影方向与桌面长边一致，赛道从左向右。
3. 启动 `GroundChickenKing.exe`。
4. 在主菜单点击“设备诊断”，核对分辨率、版本、触点上限和最近错误。
5. 点击“五点校准”，依次触摸四角与中心；五点全部变为通过后再开放游玩。
6. Development 候选版可点击“开启触点显示”观察触点位置；Release 版默认关闭此调试能力。

## 3. 首次安装与触控校准

1. 先在 Windows 触控设置或红外框厂商工具中，把触控设备映射到投影显示器。
2. 校准投影四角，使 2:1 有效画面填满 180 × 90 cm 桌面且不变形。
3. 校验上下两侧 UI：玩家 1/2 正向，玩家 3/4 旋转 180°。
4. 在游戏诊断页完成五点校准，再分别测试所有边缘按钮。
5. 用 4 个触点同时点击四个玩家加入按钮；硬件宣称支持 10 点时，再执行 10 点并发记录。
6. 把设备型号、固件/驱动、Windows 缩放、分辨率、刷新率和触点上限写入 `HARDWARE_ACCEPTANCE.md`。

## 4. 日常关机

1. 等待当前比赛结束。
2. 使用屏幕内“返回主菜单”并确认。
3. 点击“退出游戏”并确认。
4. 再关闭红外框、投影机和主机。禁止直接断电作为日常退出方式。

## 5. 故障恢复

- 触点偏移：退出游戏，重新执行 Windows/厂商映射，再启动游戏完成五点校准。
- 触控断连：重插设备并等待 Windows 识别；若不能热恢复，使用现场维护流程重启应用和设备。
- 投影重连后比例异常：恢复 1920×960 或 2:1 有效区域，禁止拉伸。
- 游戏无响应：保存 `AppData/LocalLow/GroundChickenKing/走地鸡王/ExhibitLogs` 与 Unity Player 日志后重启。游戏不保存未结束游客金币，重启应回到主菜单。
- 磁盘不足：先归档旧日志与旧发布包。展项日志单文件上限 1 MiB，并保留一个备份。
- 回滚：关闭游戏，把当前目录改名保留，解压 `GroundChickenKing-Rollback.zip`，再按每日开机流程验证版本与五点触控。

## 6. 现场禁止事项

- 不修改 `*_Data`、`MonoBleedingEdge` 或配置文件内容。
- 不使用系统拉伸把 16:9 强行铺满 2:1 桌面。
- 不在游客可访问位置放置键盘快捷方式或调试入口。
- 未完成硬件验收表和 60 分钟稳定性测试前，不把 RC 包标记为正式首版。
