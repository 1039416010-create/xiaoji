# UI 界面与角色动画规范

## 共用 UI

- 按钮：木牌九宫格；Normal 为原色，Pressed 为 94% 缩放并降低亮度，Disabled 为低饱和灰褐色。
- 标题：麦穗金、粗体、3 px 墨棕描边。
- 正文：奶油白、1.5 px 墨棕描边。
- 面板：森林绿中心、胡桃木框、草绳内边；装饰不接受射线。
- 触控目标：关键按钮物理尺寸不小于约 25 mm，延续既有防抖逻辑。

## 界面构成

| 界面 | 视觉焦点 | 操作与反馈 |
|---|---|---|
| 主菜单 | 皇冠标题、左右两只明星鸡、中央木牌按钮 | 开始、设置、退出；设置按钮增加齿轮图标 |
| 玩家加入 | 四个带玩家主题色的木框座位区 | 点击加入后按钮锁定，金币使用硬币图标 |
| 热身 | 中央标题与角色预热 | 进入下注、返回；角色播放 Warmup |
| 下注 | 上下四个独立下注框，中间状态 | 鸡、1/5/10、确认均为可见按钮；锁定后禁用 |
| 倒计时/比赛 | 五条交替色赛道、右侧方格旗 | 3-2-1、计划播放、比赛硬超时继续沿用 |
| 结算 | 皇冠、赢家摘要、咖喱鸡排提示 | 下一局、返回主菜单 |
| GameOver | 最终排名与结束原因 | 再来一局、返回主菜单 |
| 设置 | 音量、视觉强度、最大局数 | 加减、保存、取消均为按钮 |
| 诊断/校准 | 设备信息、触点和安全区 | 返回、校准步骤均为按钮 |
| 确认弹窗 | 双向可读消息和图形化确认 | `✓` 与 `✕`，不得点击空白关闭 |

## 动画状态

| 状态 | 周期 | 表现 | 约束 |
|---|---:|---|---|
| Idle | 1.20 s | 轻微呼吸与上下浮动 | 循环 |
| Warmup | 0.70 s | 左右压腿式摆动 | 循环 |
| Run | 0.32 s | 快速弹跳和轻微前后倾 | 循环 |
| Sprint | 0.22 s | 强挤压/拉伸 | 循环 |
| Stop | 0.70 s | 犹豫摇摆 | 循环 |
| Fall | 0.55 s | 向后摔倒并下沉 | 单次 |
| Recover | 0.55 s | 从倒地姿态回正 | 单次 |
| Turn | 0.70 s | 水平翻面 | 循环阶段由事件控制 |
| Interfere | 0.50 s | 向邻道探身 | 循环阶段由事件控制 |
| Celebrate | 0.55 s | 高跳并夸张回弹 | 循环至结算结束 |
| Lose | 1.10 s | 低头缓慢摇晃 | 循环 |

Animator 仅驱动 `Visual/Artwork`。赛道推进、事件选择和安全完成仍由 `ChickenController` 控制；禁止 Root Motion。
