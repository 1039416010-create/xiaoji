# 《走地鸡王》美术方向

## 核心概念

视觉主题为“手工木刻 × 乡村嘉年华 × 荒诞竞技”。画面要像一张铺在农庄节庆桌上的互动棋盘：材质温暖、轮廓夸张、按钮像真正可以拍下去的木牌，同时保持公共展项所需的强对比和远距离可读性。

## 色彩与材质

| 用途 | 色彩 | 建议值 |
|---|---|---|
| 全局底色 | 深胡桃木 | `#542C16` |
| 主面板 | 森林绿 | `#17472E` |
| 主操作 | 麦穗金 | `#FFBC2E` |
| 返回/退出 | 番茄红 | `#F57A5C` |
| 选择/诊断 | 孔雀蓝绿 | `#6DD6C7` |
| 正文 | 奶油白 | `#FFF0C2` |
| 描边 | 墨棕 | `#291309` |

- 背景使用木纹、草绳、麦秆和小面积彩旗，但中央 75% 保持安静。
- UI 使用正视角木牌与雕花框，禁止透视倾斜影响触控范围判断。
- 角色使用水粉笔触和深棕轮廓；轮廓粗细统一，局内缩小后仍可辨认。
- 所有信息采用“颜色 + 图标 + 文字”至少两种编码。

## 构图原则

- 逻辑画布固定 1920×960；背景严格 2:1 拉伸，不改变交互坐标。
- 上下两侧玩家面板维持原有 180° 朝向规则。
- 中央比赛区尽量不使用长句；金币、冠军、终点分别使用硬币、皇冠和方格旗。
- 装饰图必须 `raycastTarget = false`，不得遮挡按钮。
- 生成图不包含文字，避免生图文字错误并便于本地化。

## 资产边界

- GPT 图像负责背景、角色和装饰底板。
- Unity 负责中文、数值、布局、按钮状态、粒子、时序和动画曲线。
- `RaceDirector`、`ChickenController`、下注与结算逻辑不读取美术资产内容。
